This plugin calculates the estimated top 100 cut-off time every hour after COTD+1 for the current Track Of The Day until COTD-1 the next day

Data from new TOTDs is constantly being collected so the averages will (hopefully) get more accurate over time

Data from Troll TOTDs (1st TOTD of each month) is ignored. Data from TOTDs with a cut will also likely get deleted if the cut is done by more than 5 people within the 24 hour window.
